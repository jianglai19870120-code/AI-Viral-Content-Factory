# 错误观点：把IP理解成包装而不是持续输出

**错误观点**

把IP理解成包装而不是持续输出

误区7：把IP当成包装（一个Logo、一套视觉、几句slogan），会漏掉它本质是“持续输出”。书里说超级明星“从很多方面来说，他们本身就是产品”——C罗在场上持续贡献胜利、Lady Gaga持续输出视觉与音乐、杰斯用多年作品加《解码》的创意发行不断给粉丝新东西。IP是一次次交付堆出来的资产，不是外面套的那层皮。只做包装不做输出，看起来像IP，实际上没有内容在流动，粉丝自然留不住。

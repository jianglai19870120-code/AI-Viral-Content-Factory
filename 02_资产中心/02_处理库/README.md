# 02_处理库

存放「处理层」资产，是输入库原始资料经过拆解、分类、提炼后的结构化中间产物。

## 目录构成

- `01_观点_内容模块/`：可独立调用的观点与金句模块。
- `02_痛点_内容模块/`：按分类法、具体痛点与切入角度聚合的痛点卡。
- `03_误区_内容模块/`：明确错误认知及其来源模块。
- `04_解决方案_内容模块/`、`05_案例_内容模块/`、`06_推荐理由_内容模块/`：其他已审核的可调用模块。

## 说明

处理库是「输入—处理—输出」链路的中枢。文案结构不是处理库内容模块：它在小审通过后写入 `02_资产中心/03_输出库/01_文案结构/`，并在正文成稿前由用户填写、冻结结构四。

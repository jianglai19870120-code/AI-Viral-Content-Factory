# 从0到1的创新机会该怎么找怎么做？

**具体问题**

从0到1的创新机会该怎么找怎么做？

**步骤1：先问“什么有价值的事，是没人也在做的？”**

这是全书开篇之问。不要从“别人在做什么”出发，而从“被忽略的、尚未被创造的价值”出发，列出那些真实存在但还没人解决的需求。

**步骤2：用“重要且少数人同意”的标准筛选切口。**

一个值得做的0→1机会，必须满足两点：它重要，且绝大多数人不同意你的判断。主流赞同的方向通常已被挤满；非共识但有证据，才是你的护城河起点。

**步骤3：从小市场垄断起步，先成为唯一，再向外扩张。**

不要一上来打大市场。选一个你能在里面率先做到唯一的小市场，站稳后再沿着价值外溢逐步扩张。垄断小市场，是从0到1最稳的路径。

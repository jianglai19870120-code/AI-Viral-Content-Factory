# 03_输出库

这里是最终口播成稿的正式资产目录。

当前正式链路：

1. 用户在输入库 `清单/复盘清单` 查看已入库 CASE 卡；选题与案例是否匹配只在结构三阶段判断
2. `干货型文案正文生成Skill` 匹配爆款选题、文案结构库和 `GHK` 卡片
3. 小审审核完整来源链与候选文案
4. 通过后直接写入 `03_输出库`

当前正式目录：

- `01_文案结构/`：小审已放行的结构一至四；结构四只由用户填写和冻结。
- `02_正文成稿/`：基于已冻结结构四生成并通过小审的最终口播成稿。

这里默认保留真实正式成稿。成稿正文前固定保留 `结构调整表`，用于记录误区和步骤的原调用结构、调用地址、自动优化命名，并预留 `手动优化结构` 供后续人工调整。

# 推荐好书原始资料

这里用于存放用户自备电子书、已授权书稿或已经具备合法使用权的原始阅读资料。

支持格式：

- `md`
- `txt`
- `epub`
- `pdf`

推荐优先级：

`md > txt > epub > pdf`

分类目录：

- `01_科学创业`
- `02_能力成长`
- `03_赚钱财富`
- `04_个人IP`
- `05_AI科技`

公开说明：

- 公开仓库只保留本目录骨架和说明文件。
- 公开包不包含任何电子书正文、转录稿、摘录全文或未授权内容。
- 使用者需要自行放入合法来源资料。
- 放入资料后，由「原始资料入库统计Skill」进行入库统计，由「好书解读-内容模块拆解Skill」进行正式拆解。

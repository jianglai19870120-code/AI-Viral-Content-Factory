# 文案结构 V19 独立审核合同

仅审核 `copy-structure-handoff-v19` / `copy-structure-v19`。V18 及更早版本保留历史回执，不按本合同重写或重审。

## 必过项

- handoff、候选、预览、发布计划和写作文案表达合同的版本与哈希一致。
- 完整 FNN、大框架元数据、小框架顺序/名称和结构四留白未漂移。
- 结构一、二每张卡都有候选原句、原小框架摘录和具体的保留说明；小审逐卡核验摘录确在源内容中，且改写没有删掉原机制、步骤、场景或结果。
- 结构三每张非空卡再有同类型正式来源、章节、连续原文摘录和支撑说明；非处理库或未命中项保持整卡为空。
- 三套结构的读者切口、推理路径和交付形态逐对不同；母逻辑文字不同但实际卡片相同仍退回。
- 每张非空卡能直接讲出口，且给出对象、场景、动作、结果或判断条件；未落地的“效率、闭环、体系、价值、赋能、全链路、方法论”等机械表达退回。

## 独立审稿格式

每个 `item_review` 必须有 `candidate_quote`、`source_content_quote`、`specificness_evidence` 和可定位证据；三个 `route_comparison_reviews` 必须逐对填写三维差异。总分、`passed`、理由长度或“表达自然”等泛话不能代替这些证据。任一项无法定位即 `returned`。

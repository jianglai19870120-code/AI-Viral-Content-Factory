# AI爆款内容工厂工作台 V1 基线

版本：`workbench-v1.0.0`  
生效日期：2026-09-08  
范围：`03_工作台` 的今日工作、爆款流水线、资产中心、我的 AI 团队、数据中心与桌面桥接。

## 现役执行约定

- 正式链路固定为：小姜分配 → 专业 Agent 执行 → 小审审核 → 小姜回收。
- 所有刷新与一键成稿任务都由当前登录用户的 Codex 桌面原生桥接创建独立可见任务；不使用后台 App Server 线程或旧正文 Worker。
- 现役工作台路由 Skill 全部进入 `system-registry.json`，并已与 `.agents/skills` 的 Codex 适配入口同步；适配入口会回读对应武器库源 Skill。
- 只有获得真实 Codex 任务编号后才显示“已在 Codex 中创建”。
- 文件夹请求由独立的资源管理器桥接处理；只有确认目标目录出现在可见 Explorer 窗口后才显示“已确认打开”。
- 审核通过前不得覆盖或发布正式资产。

## 现役数据来源

- 输入库统计：输入资料核验数据库，来源数不因多张处理卡重复计数。
- 资产中心和数据中心三库统计：`workflow/asset_paths.py` 的现役目录注册表。
- 爆款流水线六阶段：源知识库、爆款内容模块、爆款选题、对标爆款、爆款结构文案、爆款成稿。
- 数据中心“内容生产转化”直接读取同一份现役流水线快照，不再读取旧结构完成快照。

## 关键门禁

- 热点事件：等待接入，不创建任务。
- 会员目录/Skill：仅在目录或 Skill 不可用时锁定；有实际内容的会员目录可按权限打开。
- 配图库：必须先选择已审核正文。
- 一键成稿：必须选择“已选中且已填写有效对标复刻拆解编号”的选题；已生成选题需明确选择重新生成。
- 已在 Codex 中运行的任务必须在对应 Codex 任务内终止，工作台不得伪造“已终止”。

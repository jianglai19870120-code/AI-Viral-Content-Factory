# AIP 工作台 UI 设计规范 v1

## 视觉真源

- 页面定稿：`../页面定稿/` 内六张已确认 PNG。
- 品牌标志：`../标志/` 内的 AIP 锁定组合，不允许把字标拆开重排。
- 图标：`../图标/manifest.json` 中登记的独立 SVG。
- 人物：`../人物头像/portrait-manifest.json` 中登记的透明 PNG；小姜只使用 `xiaojiang-master.png`。
- 页面不可引用过程稿、整张截图裁切头像、Emoji 或临时文字符号。

## 字体与层级

| 层级 | 字体 | 字重 | 桌面字号 / 行高 | 使用位置 |
|---|---|---:|---:|---|
| 关键数字 | OPPOSans | 700 | 72px / 0.9 | 主任务数量、核心数据 |
| 主任务标题 | OPPOSans | 700 | 36px / 1.2 | 左侧主任务卡 |
| 页面和卡片标题 | OPPOSans | 500 | 25px / 1.2 | 面包屑、标题、按钮、日期 |
| 正文与状态 | OPPOSans | 400 | 16px / 1.35 | 说明、状态、表格、英文副标 |
| 小型说明 | OPPOSans | 400 | 13px / 1.4 | 标签、辅助数字 |
| 侧栏导航 | Adobe Fangsong Std | 400 | 25px / 1.35 | 左侧导航与帮助中心 |

`900` 只允许用于 AIP 品牌极少数强化场景，所有常规页面禁止使用。OPPOSans 的 `400 / 500 / 700 / 900` 正式字文件到位前，页面可临时回退 `Microsoft YaHei`，但不得作为视觉验收结论。

## 颜色与轮廓

| Token | 色值 | 用途 |
|---|---|---|
| `--aip-ink` | `#151515` | 深色侧栏、文字、图表主线 |
| `--aip-canvas` | `#FBFAF8` | 页面背景 |
| `--aip-paper` | `#FFFEFD` | 卡片、弹窗 |
| `--aip-line` | `#E3DFD9` | 标准细边框 |
| `--aip-orange` | `#FF7900` | 当前选择、主操作、关键节点 |
| `--aip-blue` | `#3775D1` | 数据图、信息标签 |
| `--aip-green` | `#35B95D` | 可调度、正常状态 |
| `--aip-yellow` | `#FFB400` | 等待用户、提醒 |

页面必须以暖白和墨黑为主体。橙色只用于选中、行动和状态焦点；蓝、绿、黄只用于图表、状态和小标签，不能替代品牌橙。

## 图标、人物与组件

- 图标固定为 `24px` 网格、`1.7px` 描边、圆角线端；同一控制器内只使用一种图标语言。
- 状态使用独立 SVG 徽标叠加，不能把“可调度、审核中”等文字烘焙进头像。
- 卡片默认 `15px` 圆角，控件默认 `10px` 圆角，边框优先 `1px` `--aip-line`。
- 数字对齐优先右对齐；任务名称左对齐；右箭头仅出现在真正可进入详情的任务卡中。
- 所有页面只从本目录的 Tokens、Logo、图标、头像和组件目录取用，禁止临时自制变体。

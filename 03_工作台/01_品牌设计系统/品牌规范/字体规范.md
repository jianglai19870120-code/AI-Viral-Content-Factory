# 字体规范

| 层级 | 字体 | 字重 | 用途 |
|---|---|---:|---|
| 细字 | OPPOSans L | 300 | 细说明、模块两行名称、辅助文字 |
| 核心大字 | OPPOSans | 700 | 主任务标题、关键数字、核心产出 |
| 中等信息 | OPPOSans | 500 | 页面标题、卡片标题、按钮、日期月份 |
| 中小信息 | OPPOSans | 400 | 状态、说明、表格、英文副标、辅助数字 |
| 侧栏导航 | Adobe Fangsong Std | 400 | 左侧主导航与帮助中心 |
| 品牌预留 | OPPOSans | 900 | 仅品牌特殊强调，常规页面禁止使用 |

## 桌面字号

| 令牌 | 字号/行高 | 字重 |
|---|---:|---:|
| `display-xl` | 136px / 0.78 | 700 |
| `display-lg` | 72px / 0.90 | 700 |
| `title-lg` | 36px / 1.20 | 700 |
| `title-md` | 31px / 1.00 | 500 |
| `title-sm` | 25px / 1.20 | 500 |
| `body-lg` | 21px / 1.30 | 400 |
| `body-md` | 18px / 1.30 | 400 |
| `body-sm` | 16px / 1.35 | 400 |
| `caption` | 13px / 1.40 | 400 |

`OPPOSans L` 为细字唯一正式字体。未提供字体文件时，页面以 OPPOSans Regular `400` 回退；补入 `OPPOSans-L.ttf` 后需同步登记为正式品牌字体资源。

正式字体已存入 `03_工作台/01_品牌设计系统/字体/OPPOSans/`，由 `tokens.css` 统一注册。页面不得另行复制或加载其他字重；Microsoft YaHei 只作为浏览器异常时的末级回退。

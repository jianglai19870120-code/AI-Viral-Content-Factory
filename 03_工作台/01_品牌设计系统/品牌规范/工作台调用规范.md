# 工作台品牌 UI 调用规范

`03_工作台/01_品牌设计系统` 是工作台所有新增或改造 UI 的唯一视觉真源。现有页面只保留兼容变量，不在本规范生效时重排或改色。

## 运行时入口

工作台页面在基础样式首行加载：

```css
@import url("/brand-assets/tokens.css");
```

该地址由本机服务从本目录的 `tokens.css` 直接提供。新组件只能使用 `--aip-*` Token；`--orange` 等无前缀变量是历史页面的兼容层，禁止在新组件中使用。

## 资源调用

| 类别 | 唯一来源 | 工作台 URL 形式 |
|---|---|---|
| Logo | `标志/logo2.png` | `/brand-assets/logo.png` |
| 字体 | `字体/OPPOSans/` | `/brand-assets/fonts/OPPOSans-*.ttf` |
| 图标 | `图标/manifest.json` 登记的 SVG | `/brand-assets/icons/{icon}.svg` |
| 人物 | `人物头像/portrait-manifest.json` 登记的正式头像 | `/brand-assets/portraits/{filename}` |
| 状态徽标 | `人物头像/状态徽标/` | `/brand-assets/status/{filename}` |

页面不得复制字体文件、截取整张设计图、使用未登记头像、临时 Emoji 或新画一套控制图标。趋势图、雷达图和资产环图等数据可视化 SVG 不属于控制图标，可继续内联渲染。

当前“全屏/文件列表”与资产目录流程箭头仍是历史页面的内联控制图形，不作为未来组件资产复用；需要改造这些控件时，必须先登记正式 SVG 后再替换。当前团队渲染器已通过 `/brand-assets/portraits/` 读取正式头像；历史样式中的雪碧图仅保留为旧页面兼容，禁止新页面引用。

## 字体、图标与组件

- 细说明使用 `var(--aip-font-light)` 与 `300`；标题 `500`；关键数字 `700`；`900` 仅作品牌特殊强调。
- 图标固定 24px 网格、1.7px 描边。添加图标时，先新增 SVG、再登记 `图标/manifest.json`、最后更新组件目录；三者必须一致。
- 人物卡只放透明正式头像，运行状态必须叠加独立状态徽标，不能写入头像或使用团队雪碧图。
- 新卡片、按钮和标签使用 `--aip-card-radius`、`--aip-control-radius`、`--aip-line`，不得重新定义近似色值。

## 兼容边界

工作台既有页面中的 `--orange: #FF7200` 是视觉兼容值，保留以避免本轮改变现有页面。品牌唯一橙为 `--aip-orange: #FF7900`；新组件和后续定向改造必须使用后者。

# 色彩规范

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#151515` | 文字、深色侧栏、主要图表 |
| 暖白 | `#FFFEFD` | 卡片与弹窗 |
| 画布白 | `#FBFAF8` | 页面背景 |
| 品牌橙 | `#FF7900` | 选中态、主按钮、当前节点、重要提示 |
| 数据蓝 | `#3775D1` | 数据图表与信息标签 |
| 状态绿 | `#35B95D` | 可调度、正常、已连接 |
| 等待黄 | `#FFB400` | 等待用户、提醒 |
| 状态灰 | `#8E8E8E` | 已完成、未启用 |

橙色不可大面积作为页面背景；蓝、绿、黄仅用于图表、状态和小标签，不取代品牌橙。

# Windows 跨电脑安装与 GitHub 发布

## 支持范围

- 正式支持：Windows 10/11、Python 3.11–3.13、Node.js 20 LTS、Codex Desktop。
- 不支持：macOS、Linux；这些系统不得运行 Windows 工作台脚本。
- 项目目录可以位于任意本机路径；运行态不得写入项目目录。

## 新电脑安装

```powershell
git clone https://github.com/jianglai19870120-code/AI-Viral-Content-Factory.git
cd AI-Viral-Content-Factory
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python run.py install --dev
python run.py doctor
python run.py sync-platform --target codex
```

`python run.py install --dev` 会安装 Python 依赖、在 `03_工作台/vendor/codex-cli` 执行锁定的 `npm ci --no-audit --no-fund`，并生成仓库级 Codex Skill 适配入口；它不安装或覆盖用户其他项目的全局 Skill。缺少 Node.js、网络或锁定 CLI 时，命令会给出明确修复提示。随后用 Codex Desktop 打开本仓库根目录。

## 工作台激活

```powershell
python run.py workbench start
```

健康地址固定为 `http://127.0.0.1:8766/api/health`，页面地址为 `http://127.0.0.1:8766`。如需在登录后自动守护工作台，管理员确认后执行：

```powershell
python run.py workbench install
```

运行数据保存在 `%LOCALAPPDATA%\AI-Viral-Content-Factory\workbench`；守护安装使用 `%ProgramData%\AI-Viral-Content-Factory\workbench`。两者都不应提交到 Git。

## 发布门禁

发布前依次运行：

```powershell
python run.py doctor
python run.py validate
python run.py test
python run.py sync-platform --target codex --apply
python run.py audit-baseline
python run.py release-check
```

公开 GitHub 包只从隔离暂存目录构建，绝不直接提交当前工作区。公开规则：

- 已注册、非会员的系统源码、合同、工作台代码、输入库、处理库、输出库、配图库、索引、正式案例和 OPPOSans 字体可以进入公开包；
- 只有目录名带 `（会员专享）` 的目录及其全部子目录只保留 `.gitkeep` 或 Skill 占位入口；文件名和内容类型注册表的 `memberOnly` 字段不参与 GitHub 发布判定，后者仅用于工作台会员展示与业务权限；
- `node_modules`、`.runtime`、运行/审核/调度记录、`99_历史恢复材料`、缓存、临时文件、配图生成证据、本机绝对路径与凭证不得进入公开包；
- 推送前必须核对暂存包的 `PUBLIC_ASSETS_MANIFEST.json` 与校验和。

## v3.1.0 双轨正式发布

GitHub 只发布免费投影；飞书会员知识库从同一公开投影叠加本机会员目录，二者不能互相替代。首次启用飞书自动发布前，创建并授权企业自建应用、将应用加入会员知识库为可编辑成员，并在本机 `.env` 或安全环境变量中配置：

```powershell
AI_VIRAL_FEISHU_APP_ID=...
AI_VIRAL_FEISHU_APP_SECRET=...
AI_VIRAL_FEISHU_ROOT_URL=https://.../wiki/...
```

`AI_VIRAL_FEISHU_ROOT_URL` 指向唯一的会员知识库页面。发布器只会原位替换该页面中唯一的 ZIP 附件，不会新建版本页、修改说明文字或创建云空间文件夹。真实凭据不能提交到 Git 或发送到对话中。

先做不触发外部写入的预检：

```powershell
python run.py publish --version v3.1.0 --dry-run --skip-gates
```

随后执行正式发布：

```powershell
python run.py publish --version v3.1.0
```

正式命令依次运行门禁、构建并推送 GitHub 免费投影、创建标签、构建会员完整包，并原位替换飞书固定页面中的会员 ZIP。断点状态保存在 `%LOCALAPPDATA%\\AI-Viral-Content-Factory\\publish\\v3.1.0.json`；相同版本重跑会从已完成阶段继续。

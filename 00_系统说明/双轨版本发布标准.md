# 双轨版本发布标准

这是 AI爆款内容工厂唯一现役的版本发布合同。每次发布由小姜执行，默认同步当前工作区全部通过门禁、且符合渠道边界的改动。

## 固定规则

- 版本号由工作区所有者在指令中明确指定，格式固定为 `v主版本.次版本.修订号`；已经存在的 Git 标签绝不覆盖。
- GitHub 发布免费投影：会员专享目录只保留占位入口，凭据、运行态、审核/调度记录和历史材料不发布。
- 飞书发布会员完整 ZIP：只替换 `AI_VIRAL_FEISHU_ROOT_URL` 指向页面中唯一的 ZIP 附件；不创建页面，不改动任何说明文字。
- ZIP 小于等于 20 MiB 时单次上传；更大时自动分片上传。飞书完成合并并验证附件块后，才视为发布完成。
- 真实凭据只从本机环境变量读取：`AI_VIRAL_FEISHU_APP_ID`、`AI_VIRAL_FEISHU_APP_SECRET`、`AI_VIRAL_FEISHU_ROOT_URL`。不得写入仓库、压缩包、日志或对话。

## 调用与执行

发布前，小姜先运行只读预检；预检不会推送、上传、替换或写入发布断点：

```powershell
python run.py publish --version vX.Y.Z --preflight
```

正式命令会依次执行全部门禁、构建 GitHub 免费投影、推送分支与标签、构建会员包，并原位替换飞书 ZIP：

```powershell
python run.py publish --version vX.Y.Z
```

以后直接发送以下提示词即可：

```text
请按《双轨版本发布标准》发布 vX.Y.Z：
同步当前工作区全部合规改动。
先完成只读预检与全部发布门禁；通过后直接发布 GitHub 免费版，
并原位替换飞书会员知识库页面中的会员 ZIP。
不得修改飞书页面说明文字，不得覆盖已有 Git 标签；
如失败，保留断点并从失败阶段安全重试。
```

## 失败恢复

发布状态保存于 `%LOCALAPPDATA%\AI-Viral-Content-Factory\publish\vX.Y.Z.json`。若 GitHub 已完成而飞书失败，或遇到临时网络失败，不要修改待发布内容，也不要更换版本号；使用同一版本执行恢复：

```text
请按《双轨版本发布标准》恢复 vX.Y.Z 双轨发布。
保持原发布内容不变，只从已保存断点继续。
```

恢复命令仍为：

```powershell
python run.py publish --version vX.Y.Z
```

若预检发现固定飞书页面没有 ZIP、存在多个 ZIP，或当前附件已被人工替换，发布必须停止并由工作区所有者先处理页面状态；系统不会猜测目标附件或删除额外文件。

# 小姜调度 Skill

小姜识别任务、分配专业 Agent、等待小审并回收结果；不直接替代专业执行。

通用文案任务固定路由：小拆调用 `copy-structure-generation`（锁定 V3 完整口播规范快照）→ 用户填写结构四 → 小写调用 `final-copy-generation`（锁定同一正文规则快照）→ 小审逐规则、逐卡/段核验后放行。直接 Codex 路径使用完整填写的 `owner-filled-direct`；工作台路径还须用户以 `√` 完成 `owner-frozen`。内容类型不参与路由。

拆解任务的完成链路固定为：拆解候选 → 小审 `approved` → 正式发布 → 清单与数据中心回写 → 回执记录。小姜只在回写回执存在且当前正式文件哈希可回溯时回收“已拆解”；退回、候选、哈希漂移或来源不明均不得更新清单状态。

对标编号调用前先执行案例同步预检。注册表启用 `manualEditPolicy: owner-approved` 时，工作区所有者手动修改或改名的正式对标拆解无需小审；只按唯一编号同步登记，并以人工确认回执重绑当前路径与哈希。系统不得改写该手工文件；重复编号或身份字段不一致时阻断。

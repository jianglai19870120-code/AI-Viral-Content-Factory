# Agent 路由表

这张表只解决一个问题：用户需求默认交给哪个 Agent。  
具体调用哪个 Skill / 程序 / 工具，由负责 Agent 自己根据 `能力清单.md` 和 `调用规则.md` 决定。

## 路由硬规则

- 小姜只做岗位分配，不管理 Agent 内部每一步调用。
- 表中“是否必须小审”为“是”的任务，必须先有小姜正式分配记录，专业 Agent 执行器才允许启动。
- 表中“是否必须小审”为“按能力”的任务，只有在小审已建成对应审核能力时，才按正式门禁执行；未建成时必须明确标记为“审核待建设”。
- 小姜正式分配记录必须包含任务名称、任务类型、目标 Agent、输入来源、是否需要小审、创建时间。
- 每个 Agent 必须维护自己的 `能力清单.md`。
- 任务不在 Agent 能力清单内时，Agent 必须退回小姜。
- 对于已经建成审核能力的成果，没有小审审核闭环时，不允许进入正式资产。
- 小姜无法分配时，必须退回用户，不允许代做。

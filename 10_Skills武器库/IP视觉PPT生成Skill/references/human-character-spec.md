# 人物型 IP 角色包规范

这个 skill 里的人物型角色，不按吉祥物思路设计，而按“真人漫画化主讲人”处理。

## 必须锁死

- 发型轮廓
- 眼镜类型
- 基础服装
- 脸部整体气质

## 可变化

- 手势
- 姿态
- 表情
- 是否带话筒
- 是否出现品牌话筒牌

## 表演要求

- 表情和肢体可以夸张
- 但不能夸张到认不出同一个人
- 更像“会演戏的角色”，不是静态头像

## 线条要求

- 以黑线/白线为主
- 尽量减少角色自带大面积色块
- 页面主配色由 PPT 版式承担

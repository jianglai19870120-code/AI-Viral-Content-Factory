# 合格成图基准

正式正向案例：`../assets/quality-reference/approved-visual-note-page-01.png`

SHA-256：`6b5774cbcec3c68e224de41bb717041716b4fcf79acb4a2687e3cd3579f92016`

该图只作为视觉品质与完成态基准。每次正式生图前必须真实查看并作为参考图输入，重点比照：

- 顶部标题已经填入清晰、完整的中文，不存在空白标题栏。
- 页面不是单一人物插画，而是标题、2–5 个原文信息模块、人物和对象关系共同组成整页视觉笔记。
- 每个文字模块都与邻近的小场景或图形形成明确语义配对，文字不是孤立标签，图形也不是装饰。
- 信息区有主次、流程或因果关系，画面饱满但不拥挤，手绘边框、箭头和红色强调服务于信息关系。
- 所有卡片均已填字；不得保留“后续填写”的空白框、空白横幅或模板占位区。

该图不是当前页面的语义来源。不得复制案例中的“第一性原理”等文字，也不得机械复用坑洞、放大镜、天平、灯泡等对象。当前页的可见中文只能来自当前页 `source_text_ledger`，当前页的对象和关系只能来自当前页 `keyword_visual_mappings`。

判退对照：只有人物和若干图标、没有中文；有空白卡槽；把案例文字带入新页；文字与图形不对应；同一套对象关系跨页重复。

# 正文语义质量门禁

用于 `final-copy-v3` 成稿前自检和小审独立语义复核；它补充但不替代正文合同中的冻结内容、完整 FNN、事实边界和段落注释校验。

## 退回规则

以下任一项无法给出候选中的具体证据，即为 `failed`，不得发布。

| 检查项 | 审核问题 | 合格证据 |
| --- | --- | --- |
| 逻辑不自相矛盾 | 是否把必要但不充分的条件写成无用条件，或被后文自己推翻？ | 标出相关前后段，说明两者的条件关系。 |
| 抽象表达可落地 | 每个关键抽象词是否对应场景、行为、选择或判断标准？ | 标出抽象词及其在候选中的落地表达。 |
| 段落不跑题 | 每段是否直接服务标题和当前 FNN 功能？新话题是否有因果桥接？ | 标出该段对标题和前后框架的推进关系。 |
| 方案可执行可验证 | 方案是否明确动作、对象、验证信号和停止条件？ | 标出四项；缺任一项即退回。 |
| 开头具备停留理由 | 前三句是否让目标读者看见对象、冲突或反常识、继续误判的代价？ | 引用前三句并逐项说明。 |
| 段落有新增推进 | 每段是否新增原因、代价、边界、例子或动作，而非同义复述？ | 说明相对前段新增的内容类型。 |
| 口播完整连贯 | 断句是否仍构成完整意思，设问是否有答案，概念是否被解释？ | 标出一个完整口播单元与衔接方式。 |
| 收束降低行动门槛 | 行动引导是否只给一个最小、低成本、可立刻开始的动作？ | 标出唯一行动及其完成判据。 |

审稿摘要不得只写“已检查”或“表达自然”；必须引用候选中可定位的句子或 FNN 编号。不得为凑合通过而补写外部事实、数据、案例或用户未冻结的核心结论。

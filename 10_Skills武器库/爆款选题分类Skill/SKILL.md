# 爆款选题分类Skill（V4.2）

## 作用定位

本 Skill 负责把 `02_资产中心/04_选题库/01_对标账号` 中的博主对标表，整理成 `02_资产中心/04_选题库/02_选题分类` 的索引资产。

这个索引库只服务一件事：

`爆款选题 -> 结构三按需匹配已审核案例卡 -> 用户冻结结构四 -> 正文成稿`

固定做六件事：

1. 从账号表 `视频信息` 列提取原选题。
2. 判断原选题已有的爆款元素。
3. 生成固定 4 字的核心关键词，其中至少 2 字取自选题原文。
4. 按 8 大爆款元素优化成更适合点击的爆款选题。
5. 按一级分类写入 6 张索引表并生成审核报告。
6. 按爆款门槛过滤选题：点赞数 > 1000，或在该账号文件内排前 20%。

禁止：

- 不改原始账号表。
- 不生成文案。
- 不拆解独立开头卡。
- 不读取 `文案` 列做选题提取、总结或分类。
- 不生成任何人工选题入口清单。
- 不生成任何人工开头入口清单。

## 标准执行顺序（两阶段固化）

本 Skill 在总流水线 S4 中必须按以下两阶段顺序执行，**阶段A 未完成（选题表未更新）不得进入阶段B**：

- **阶段A · 扫输入库更新选题表**：先读取 `02_资产中心/04_选题库/01_对标账号` 下的对标账号表（`.xlsx`/`.xls`），提取 `视频信息` 列，按「选题处理注册表」增量将新博主 / 新选题写入 `04_选题库/02_选题分类/` 6 张选题表（已分类的不重复）。此阶段只做「拉新 + 更新」，不重排、不改动旧行。
- **阶段B · 分类拆解选题**：对选题表内的选题做一级分类拆解（生成 4 字核心关键词、判断原爆款元素、按 8 大爆款元素优化、爆款门槛过滤），写入对应一级分类表并生成审核报告。

> 强调：必须先确保阶段A 把输入库中的新对标账号 / 新选题**更新进选题表**，阶段B 才对这些选题做分类拆解。输入来源唯一锁定 `04_选题库/01_对标账号`，不得从其它目录读取选题。

## 默认路径

- 输入目录：`02_资产中心/04_选题库/01_对标账号`
- 输出目录：`02_资产中心/04_选题库/02_选题分类`
- 审核目录：`.workbuddy/local_only/reports/dry-goods-pipeline`

外部用户模式：

- 用 `--input-dir`、`--output-dir`、`--audit-dir` 显式传入自己的目录。

## 数据中心回写

小审审核放行后，必须为本次已扫描完成的每个账号表（包括爆款过滤后写入 0 条的账号）登记当前文件版本。不得在候选、失败、取消或审核退回时登记。

```bash
python -m workflow.data_center record-source-processing \
  --source-type benchmark \
  --source-file "02_资产中心/04_选题库/01_对标账号/<账号表>.xlsx" \
  --audit-receipt "<正式小审回执路径>" \

```

工作台右上角刷新只读取这份已审核来源版本记录；未登记的新账号或文件哈希变化的旧账号会显示为“对标账号可处理”。

## 输入字段

必需字段：

- `视频信息`（标题列）

> **标题列识别规则**：列名允许不是 `视频信息`。脚本先认列名 `视频信息`；若找不到，则按「# 密度」自动识别——统计每列含 `#` 的单元格数，排除 `链接`/`点赞数` 等已知非标题列后，取含 `#` 最多且严格大于其他列的列作为标题列（标题列通常每条选题都带 `#话题`）。仍找不到才报「缺少标题列」。

建议字段：

- `点赞数`
- `链接`

字段规则：

- `视频信息` 是唯一正式选题来源。
- `链接` 用于去重；没有链接时按 `博主名 + 原选题` 去重。
- `视频信息` 为空时，该行写入审核报告，不进入分类表。

## 输出分类表

只写以下 6 张表：

- `01_科学创业选题表.md`
- `02_能力成长选题表.md`
- `03_赚钱财富选题表.md`
- `04_个人IP选题表.md`
- `05_AI科技选题表.md`
- `99_其他类型选题表.md`

一级分类由文件名表达，表内不再重复写一级分类。

每张表为 Markdown 格式，字段固定为 9 列：

```
核心关键词,选题,原爆款元素,博主名,点赞数,链接,是否选中,对标复刻拆解编号,状态
```

表格格式补充：

- 表头分隔行后直接进入正式数据行。
- 表格最后 1 条正式数据行之后，必须额外保留 **1 个空白行**，再进入品牌尾注块。
- 这个空白行属于正式输出格式的一部分；`classify_benchmark_topics.py` 与 `refresh_topic_stats.py` 重写文件时都必须保留，不得在重跑时吞掉。

字段规则：

- `核心关键词`：固定 4 字，至少 2 字取自选题；相近选题复用同一关键词。
- `选题`：从 `视频信息` 清洗后的原始选题。
- `原爆款元素`：只判断原选题已经具备的元素；没有明显元素写 `无明显元素`。

**V4.2 选题表字段与直连规则**：

- `是否选中`：默认为空，由用户手动填写。设为「是」表示该选题已经过确认，可以直接进入文案结构生成流程；「否」只表示不可进入直连流程，刷新状态时不得删除该行。
- `对标复刻拆解编号`：由用户填写已审核 `GHX-xxx`。结构生成只接受唯一、已选中且该编号已审核的行。
- `状态`：默认为空。只有经小审批准的“选题—结构发布索引”绑定才可更新；不得按文件名前缀或目录猜测。

**V4.2 选题去重**：`classify` 写入新表前可按既有策略去重；`refresh_topic_stats.py` 不得去重、删除或重排历史行。直连结构任务遇到同名行必须人工消歧。

**V4 新增功能**：

- **核心关键词 4 字约束**：关键词固定为 4 个汉字，其中至少 2 个字必须从选题中截取。
- **关键词排序**：表内数据按核心关键词字母序排序，不再按博主名或生成顺序排序。
-   **统计区**：每张表顶部自动生成统计块（五态漏斗，前 2 态由本 Skill 生成，后 3 态由 `refresh_topic_stats.py` 校正）：
  ```
  **统计：**
  *1、待选中选题，共 X 条*
  *2、待生成结构，共 X 条*
  *3、已生成结构，共 X 条*
  *4、已手动优化，共 X 条*
  *5、已生成正文，共 X 条*
  ```
  - 待选中选题 = `是否选中` 为空的行数
  - 待生成结构 = `是否选中=是` 且没有当前行、对标编号的已审核发布索引绑定
  - 已生成结构 / 已手动优化 = 由 `refresh_topic_stats.py` 依据发布索引的输出 hash、候选 hash、审核回执校正（本 Skill 生成时填 0）

## 爆款过滤规则

选题进入分类表前必须通过爆款过滤门槛：

1. **点赞数 > 1000**：直接进入分类表。
2. **在该账号文件内排前 20%**：即使点赞数 ≤ 1000，只要在该文件所有选题的点赞量排名中位于前 20%（按点赞数降序排列，取前 `ceil(总数×0.2)` 条），也可进入分类表。文件极少时至少保留最高赞的一条。
3. 两条都不满足的选题，写入审核报告 `爆款过滤剔除` 段落，不进入任何分类表。
4. 点赞数缺失或无法解析为数字的，视为 0，必然触发过滤。

## 8 大爆款元素

8 大爆款元素框架（源自课程「账号策划-8大爆款元素」）已完整内联如下。Skill 必须完整保留以下 8 类，不允许缩成 4 类：

1. `成本`：钱、时间、学习难度、机会成本、步骤数、低门槛。
2. `人群`：身份、阶段、收入水平、能力水平、困境人群。
3. `奇葩`：反常、新奇、离谱、极少见的场景或做法。
4. `难吃难用差`：最差、最难用、最失败、避坑、负面样本。
5. `反向操作`：不是 A 而是 B、越 A 越 B、反着做、常识反转。
6. `怀旧`：童年、过去年代、共同记忆、老物件、旧场景。
7. `荷尔蒙`：吸引力、异性关系、身材外貌、恋爱和欲望相关。
8. `头牌`：行业第一、最大、最贵、最强、头部人物、知名品牌或极端结果。

## 关键词规则（V4）

核心关键词是后续匹配今日复盘时使用的二级话题分类，固定 4 个汉字。

**V4 核心约束：**

1. **2 字来自选题**：关键词中至少有 2 个汉字必须从原选题文字中截取。
2. **4 字语义完整**：关键词必须是语义完整、贴近选题核心意思的 4 字中文概念短语，
   生成后须检查这 4 字是否可以作为一个独立、有具体含义的词组在中文语境中使用。
   不可机械截取选题前 N 个汉字充当关键词。
3. **剩余 2 字语义贴近**：未取自选题的 2 字，必须根据选题核心主题，从标准关键词体系
   中选取最贴近语义的词根拼接，不可随意填字凑数。
4. **关键词决定分类**：生成的关键词含义，决定该选题进入哪张一级分类表。

**禁止：**

- 以「怎么」「为什么」「可以」「在一个」「别学了」「只想说」等无法独立表意的碎片为关键词
- 机械截取选题前 N 个汉字充当关键词（如 `别学了先`、`在一个加`、`为什么你`、`快速进入`）
- 关键词只含选题的文字碎片，但整体不构成可理解的中文概念

**关键词生成策略：**

1. 从选题语义中提取主题词（最能概括选题核心概念的词，来自选题原文）。
2. 用主题词匹配标准关键词体系，取语义最近的标准词作为关键词。
3. 如没有精确匹配，从标准体系中拼接：主题词 2 字 + 标准后缀 2 字 = 4 字语义完整关键词。
4. 任何位置都不能产出无意义 4 字碎片——如无法生成语义完整的关键词，标记为「待LLM确认」写入审核报告。

标准关键词体系（4 字）：

- 科学创业：`创业起步 / 客户成交 / 产品定价 / 产品设计 / 商业模式 / 利润模型 / 增长策略 / 一人公司 / 市场验证`
- 赚钱财富：`副业赚钱 / 第一桶金 / 财富认知 / 资产配置 / 房产选择 / 金融认知 / 原始积累 / 赚钱思维`
- 个人IP：`账号运营 / 涨粉方法 / 内容定位 / IP变现 / 账号避坑 / 平台认知 / 视频创作 / 私域运营 / 直播带货`
- 能力成长：`职场成长 / 工作选择 / 执行能力 / 认知升级 / 时间管理 / 人生翻盘 / 社交关系 / 学习方法 / 情绪管理 / 行动习惯 / 决策判断 / 表达技巧 / 竞争策略 / 作息自律 / 自我成长`
- AI科技：`智能应用 / 智能提效 / 智能团队 / 智能就业 / 模型工具 / 自动流程`
- 其他类型：只保留无法稳定归类的残余，也必须生成 4 字语义完整的关键词。

关键样例：

- `高端客户付钱，是因为不付的代价更贵` → `客户成交`（客户=来自选题 + 成交=语义匹配）
- `一人公司起步阶段，90%的人注定失败` → `一人公司`（4 字均来自选题，语义完整）
- `创业的方法...找到持续存在的需求` → `创业起步`（创业=来自选题 + 起步=语义匹配）
- `别学了，先做完` → `行动优先`（行动=语义提取，非碎片截取）
- `为什么你赚不到钱` → `赚钱困境`（赚钱=语义提取，非碎片截取）
- `如何在一个加速分流的时代往上走` → `趋势向上`（趋势=语义提取）

## 选题清洗规则

从 `视频信息` 提取选题时：

- 只保留第一个 `#` 之前的内容，`#` 后全部视为话题标签丢弃。
- 压缩换行和多余空格。
- 去掉明显平台噪音和重复空白。
- 先判断清洗后的内容是不是完整、单句、信息密度正常的选题；完整表达优先，不把 `30` 字当硬上限。
- 如果是完整单句，即使略长，只要仍像一句正常选题，也允许整句保留。
- 只有当标题明显过长、包含多句、口播解释串、重复修饰或后半段延展解释时，才做压缩。
- 压缩优先保留"完整主张句"，而不是机械取前 30 字。
- 禁止输出残句、悬空数字、只有前半句的短片段。
- 遇到 `提示词 / 口播解释 / 冒号解释 / 竖线分隔 / 长段落`，必须先提炼真正题眼。
- 遇到 `如何快速进入一个领域 提示词1：找到20%核心知识...` 这类内容，`原选题` 必须提炼为 `如何快速进入一个领域`。
- 遇到 `题眼 + 解释句`、`题眼 + 方法展开`、`题眼 + 案例说明`，只保留可以独立成题的题眼。
- 审核报告必须复核"长文案提炼后仍超长"，正式目标为 0。
- 真正发生压缩时，审核报告必须写明原始标题、压缩后标题和压缩原因。

## 一级分类规则

分类不做简单关键词命中，也不沿用旧表所在一级分类。正式顺序是：

1. 根据 `原选题` 判断真实主题，生成 `核心关键词`。
2. 根据 `核心关键词` 决定进入哪张一级分类表。
3. 如果关键词和旧一级分类冲突，以关键词为准迁移表格。

### 科学创业

创业、商业模式、公司经营、产品、组织、增长、战略、融资、企业服务、创新商业化。

### 能力成长

学习、认知、效率、行动力、决策、表达、习惯、复盘、自我管理、职业能力。

### 赚钱财富

赚钱、副业、收入、财富、现金流、职业变现、商业机会、投资理财、财务自由、第一桶金、被动收入、单干赚钱、生意变现。

### 个人IP

自媒体、短视频、内容创作、账号定位、涨粉、流量、私域、个人品牌、信任、成交、IP 变现。

### AI科技

AI 工具、模型、Agent、编程、自动化、科技产品、AI 应用、技术趋势、平台发布。

### 其他类型

信息不足、多类冲突、无法判断主要承诺，或不属于当前五类。

## 读取老式 Excel

当前账号库里可能同时存在三类 Excel 输入：

- 标准 OOXML `.xlsx`
- 老式 Excel `.xls`
- 文件名写成 `.xlsx`、但真实内容仍是老式 Excel 的伪装文件

脚本必须：

- 先判断文件真实格式，不以后缀名为准。
- 读取标准 xlsx。
- 读取老式 Excel `.xls`。
- 读取伪装成 `.xlsx` 的老式 Excel 文件。
- 只有真正不可识别或损坏的文件，才写入审核报告。
- 不允许因为单个文件不可读中断整批。

## 验收标准

- 六张表为 Markdown 格式，9 列字段（去掉了「发布时间」「优化后爆款选题」「结构类型」「文案结构」列）。
- 每张表最后 1 条正式数据行后，额外保留 1 个空白行，再写品牌尾注。
- `核心关键词` 固定 4 个汉字，至少 2 字取自选题。
- 表内数据按核心关键词字母序排序。
- 每张表顶部包含五态统计块（待选中 / 待生成结构 / 已生成结构 / 已手动优化 / 已生成正文），前 2 态为生成时实际值，后 3 态由 `refresh_topic_stats.py` 校正。
- `refresh_topic_stats.py` 只原位更新第九列状态和统计块；不得删除、合并、重排或改写前八列。
- 「是否选中」和「对标复刻拆解编号」由用户手动填写。
- 「状态」只由 `refresh_topic_stats.py` 根据受控发布索引校正；结构文件链接不写回表格。
- 新增爆款过滤门槛：点赞数 > 1000，或在该账号文件内排前 20%。
- 不满足过滤门槛的选题写入审核报告，不进入分类表。
- 表内不再出现任何一级分类字段或人工勾选字段。
- 不再生成人工正文入口清单或人工开头入口清单。
- 每条选题只进入一张分类表。
- 重复运行不重复追加同一链接。
- 不可读账号表进入审核报告。
- ChatGPT 对话中已有样例优先采用原优化结果。
